# 3-minute demo
1. User asks for a relaxed two-day Dubai trip with an $800 budget.
2. TRAVELIA creates a personalized itinerary.
3. Ask for tomorrow afternoon's best option.
4. Trigger heavy rain.
5. TRAVELIA detects the conflict and replans.
6. Dashboard changes the itinerary.
7. User asks to book the new activity; agent requests explicit confirmation.
8. Close: "Your itinerary adapts to the world around you."
